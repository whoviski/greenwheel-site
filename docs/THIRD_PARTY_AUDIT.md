# Сторонние сервисы сайта GreenWheel

Проверка кода репозитория на 9 ноября 2026 г. Учтены HTML, CSS, JS, шрифты и зависимости. Форм, API и серверных журналов в репозитории нет.

| Компонент | Что передаёт | Куда (страна) | Нужен ли | Решение |
| --- | --- | --- | --- | --- |
| Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`), семейства Manrope и Unbounded | При загрузке CSS и файлов шрифта браузер обращался к Google: IP-адрес, User-Agent и обычно адрес страницы | Google LLC, США | Шрифты нужны для оформления, запрос к Google — нет | Удалено. Файлы лежат в `fonts/manrope.woff2` и `fonts/unbounded.woff2`, лицензия SIL OFL 1.1 — `fonts/OFL.txt` и `fonts/OFL-unbounded.txt` |
| Аналитика, реклама, карты, видео | Не было | — | Нет | Не подключались |
| npm- и pip-зависимости проекта | Нет `package.json` и `requirements.txt`. Сеть из зависимостей проекта не вызывается | — | Нет | Не добавлялись |
| `localStorage`, ключ `gw-cookie-consent` | Никуда не отправляется. В браузере лежит выбор баннера | Устройство посетителя | Да, чтобы помнить выбор | Оставлен. Ставится только после нажатия кнопки баннера. Срок в коде — 365 суток |
| HTTP-cookie и `sessionStorage` | Нет записей | — | Нет | Не используются |
| Хостинг статических файлов | Браузер запрашивает файлы сайта у того сервера, где включена публикация. Репозиторий рассчитан на GitHub Pages. Состав журналов хостинга кодом не задаётся | Если это GitHub Pages — инфраструктура GitHub за пределами РФ | Для публикации страниц | В коде нет отдельной передачи анкетных данных |

Необязательные скрипты до согласия не загружаются: подключать их можно только в `js/consent.js`, внутри `apply`, и только если соответствующий флаг равен true. Сейчас эта функция ничего не загружает.
